# Getting help

- **Documentation**: installation guide, tutorials, examples and API reference at
  <https://egttools.readthedocs.io/>.
- **Questions and ideas**: [GitHub Discussions](https://github.com/Socrats/EGTTools/discussions).
  Search there first; your question may already have an answer.
- **Bugs, performance problems and documentation errors**: open an
  [issue](https://github.com/Socrats/EGTTools/issues/new/choose) using one of the forms.
- **Security problems**: follow [SECURITY.md](SECURITY.md); do not open a public issue.

EGTtools is maintained on a best-effort basis. Issues with a minimal, runnable example get
answered fastest.

If you use EGTtools in your research, please cite it as described in the
[README](README.md#-citation) and [CITATION.cff](CITATION.cff).
